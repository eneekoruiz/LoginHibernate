# LoginHibernate - Ride-Sharing App

Ride-sharing web application built with JSF and Hibernate ORM.

## What it covers

- role-based registration and authentication
- ride creation and booking flows
- JSF pages with managed beans
- JPA/Hibernate persistence with H2

## Stack

- Java
- JSF
- Hibernate
- Maven
- H2
