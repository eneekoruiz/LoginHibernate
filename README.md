# LoginHibernate - Ride-Sharing App

Ride-sharing web application built with JSF and Hibernate ORM.

## What it covers

- role-based registration and authentication
- ride creation and booking flows
- JSF pages with managed beans
- JPA/Hibernate persistence with H2

## Stack

- Java
- JSF
- Hibernate
- Maven
- H2

## Architecture

JSF pages bind to backing beans that coordinate authentication and ride-sharing actions. The business layer delegates persistence to Hibernate, keeping entity sessions and queries separate from view state.
